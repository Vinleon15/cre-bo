# Бот-дайджест сделок с коммерческой недвижимостью

Собирает новости с cre.ru (и параллельно с публичной веб-версии канала
@CRERussia), вытаскивает из них **покупателя, продавца и локацию** и присылает
сводку в Telegram по запросу.

```
cre.ru ──┐
         ├──> SQLite ──(Claude)──> карточки ──> бот: /digest
канал  ──┘
```

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env      # заполнить
python main.py
```

Что нужно получить заранее:

| Переменная | Где взять |
|---|---|
| `BOT_TOKEN` | @BotFather → `/newbot` |
| `OWNER_IDS` | @userinfobot → твой numeric id |

Ключ Anthropic нужен только в платном режиме — по умолчанию он выключен.

## Три режима разбора

Переключаются прямо в боте командой `/mode`, выбор сохраняется между
запусками. В `.env` задаётся только стартовый режим.

| Режим | Стоимость | Качество | Что нужно |
|---|---|---|---|
| Бесплатно | 0 | стороны находит примерно в 8 заголовках из 10, сложные формулировки пропускает | ничего |
| GigaChat | бесплатный лимит для физлиц, дальше от 600 ₽/мес | понимает живой текст, читает тело статьи | Сбер ID, ключ авторизации |
| Claude | ~0,5 ¢ за новость | лучше всех различает нюансы вроде «покупателя не раскрывают» | зарубежная карта |

После смены режима имеет смысл выполнить `/reparse` — уже собранное
переразберётся заново, заново скачивать ничего не нужно.

### GigaChat: что понадобится

Регистрация на developers.sber.ru через Сбер ID, создание проекта
GigaChat API, затем ключ авторизации — длинная строка Base64. Её
и вписывают в `GIGACHAT_AUTH_KEY`.

Отдельная особенность: Сбер использует сертификаты Минцифры. Если они
не установлены в системе, запросы упадут на проверке TLS. Правильное
решение — поставить сертификаты с сайта Госуслуг. Параметр
`GIGACHAT_VERIFY_SSL=0` отключает проверку и снимает симптом, но при
этом соединение перестаёт быть защищённым от подмены — это временный
костыль, а не решение.

Проверить связь можно командой `/check` в боте.

Личный Telegram-аккаунт **не нужен**: канал читается через публичную
веб-версию, доступную без авторизации.

## Команды

| Команда | Что делает |
|---|---|
| `/update` | забрать свежее и разобрать |
| `/digest` | сводка за сутки |
| `/digest 7` | за неделю |
| `/digest 3 Москва` | за 3 дня, только где в локации есть «Москва» |
| `/mode` | выбрать режим разбора |
| `/reparse` | переразобрать собранное заново |
| `/check` | проверить связь с GigaChat |
| `/sources` | сравнение полноты источников |
| `/status` | что накопилось в базе |

Сбор запускается только командой `/update` — фонового процесса нет, скрипт
можно держать на своём компьютере и запускать, когда нужна сводка. История
никуда не девается: сайт отдаёт архив, так что после перерыва всё дочитается.

## Проверка полноты источников

Первую неделю имеет смысл держать `SOURCES=site,tg`, а потом посмотреть
`/sources`. Дедупликация идёт по нормализованному **заголовку**, поэтому одна
и та же новость с сайта и из канала схлопывается в одну запись, а «уникальных»
считается тот источник, который принёс её первым.

Если у канала уникальных около нуля — он ничего не добавляет сверх сайта,
и можно поставить `SOURCES=site`. Ожидание именно такое: каждый содержательный
пост канала ссылается на статью cre.ru, а сайт публикует примерно в десять раз
больше материалов. Но проверить на своих данных дешевле, чем спорить.

## Формат карточки

```
🏢 Бизнес-центр «Обсидиан»
Госкорпорация приобрела офисное здание на севере Москвы
👤 Покупатель: Дом.РФ
🏷 Продавец: —
📍 Локация: Москва, север
💰 —
📊 сделка закрыта
🔗 Источник · 24.07
```

Прочерки — норма. Стороны сделок часто не раскрывают: в продаже
«Галс-Девелопмента» более чем на 100 млрд рублей имена покупателей не назвали
ни банк, ни сама компания. Модель намеренно не догадывается: пустое поле
честнее выдуманного.

Ниже карточек идёт компактный хвост — назначения и аналитика одной строкой
со ссылками. Не нужен — убери рубрики 7, 3, 57 из `CRE_CATEGORIES`.

## Вежливость к источникам

`REQUEST_DELAY` держит паузу между запросами (по умолчанию 1.5 секунды, ниже
1 секунды не опускается), запросы идут с понятным User-Agent. В дайджест
попадает пересказ своими словами и ссылка на оригинал, а не копия текста.
Материалы cre.ru защищены авторским правом — сводка для личного чтения это
одно, публикация или перепродажа — совсем другое.

## Что не проверено вживую

Код написан, но не запускался: у среды, где он собирался, не было доступа
в сеть. Синтаксис проверен, логика прямолинейная, но при первом запуске
возможны правки в парсере тела статьи — вёрстку cre.ru я видел только
в текстовом виде. Заголовок, дата, рубрика и лид берутся из meta-тегов,
поэтому даже при полном сбое разбора тела карточка соберётся.

## Что легко добавить дальше

- RSS вместо разбора HTML: у cre.ru есть страница `/rss_list`, стоит открыть
  её и посмотреть, какие ленты отдаются — это надёжнее парсинга;
- мгновенные алерты по ключевым словам (район, компания, сумма от N);
- выгрузка в Excel или Google Sheets;
- второй источник для перекрёстной проверки слухов.
